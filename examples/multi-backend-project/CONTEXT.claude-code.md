# Claude Code Overlay

Additional instructions specific to Claude Code.

## Tool Preferences

- Use the built-in Grep and Glob tools instead of shell commands for searching.
- Use the Read tool to view files rather than `cat` or `head`.
- Prefer the Edit tool over `sed` or `awk` for modifying files.

## Commit Style

- Write commit messages in imperative mood ("Add feature" not "Added feature").
- Keep the first line under 72 characters.
- Do not commit unless explicitly asked.
