# Phase 1 Agent 5: Claude Code Backend Generator

## Deliverables

1. **Generate `.claude/settings.json`** — isolation mode, model preferences, permissions from manifest `settings.claude-code`
2. **Generate `.claude/agents/*.md`** — copy agent Markdown files from cache/local, inject model + parameters into YAML frontmatter
3. **Generate `.claude/skills/*/SKILL.md`** — copy skill directories from cache/local
4. **Generate `.mcp.json`** — render MCP server configurations from manifest, resolve `${VAR}` env var references
5. **Auto-generated file headers** — all generated files include the marker comment
6. **Implement the `Backend` trait** fully for `ClaudeCodeBackend`

## Modules to Work In

- `src/backends/claude_code.rs` — the main implementation
- `src/backends/mod.rs` — may need to adjust `ResolvedEnvironment` as needed


## Generated File Formats

### `.claude/settings.json`
```json
{
  "// AUTO-GENERATED BY agx. DO NOT EDIT.": "",
  "permissions": {
    "allow": ["Bash(npm test)", "Bash(npm run lint)"],
    "deny": ["Bash(rm -rf)"]
  },
  "environment": {
    "CLAUDE_CODE_DISABLE_BACKGROUND_TASKS": "1"
  }
}
```

### `.mcp.json`
```json
{
  "mcpServers": {
    "playwright": {
      "url": "https://mcp.playwright.dev/sse"
    },
    "filesystem": {
      "command": "npx",
      "args": ["@anthropic-ai/mcp-server-filesystem", "./src"],
      "env": {
        "ALLOW_WRITE": "true"
      }
    }
  }
}
```

### Agent frontmatter injection
Given an agent with `model: opus`, the generated `.claude/agents/my-agent.md` should have:
```markdown
<!-- AUTO-GENERATED BY agx. Source: local ./agents/my-agent.md -->
---
model: opus
---

[original agent content]
```

## Testing Strategy

- **Settings generation:** Create a manifest with various settings, generate, verify JSON output
- **MCP generation:** Test URL-based and command-based servers, test `${VAR}` resolution
- **Agent placement:** Test local agent copy, test model injection into frontmatter
- **Skill placement:** Test local skill directory copy
- **Isolation modes:** Verify strict mode generates appropriate settings
- **Idempotency:** Generate twice, verify output is identical
- Use `tempfile::tempdir()` for all output

## Dependencies on Other Agents

- Needs cached assets to be in place (Agent 4 for cache structure, Agent 2 for git extraction)
- For testing, can create mock cache directories with test fixtures

## Integration Points

After this agent completes:
- `agx generate` produces a valid Claude Code environment
- `agx install` (when wired up) goes from lockfile → working .claude/ directory
- The generated environment can be used directly by Claude Code
